## 正文

### 这是什么

一个本地小工具：给它一张截图（或一个窗口），它把画面按你画的区域切开，告诉你

- 每个数字区域**读到了什么**、每个字 top-3 是什么、卡在哪个字上；
- 每个卡格/单位格**最像谁**、分数多少、是否过阈值；
- 模板库现在覆盖了什么、缺什么（比如「缺 0/5/6/7/9」）；
- 一句「你现在该补什么」。

它不读内存、不注入、不自动操作，只吃截图。

### 为什么做

我在做一个自走棋类玩法的记牌器，最烦的不是「认错了」，是**认错的时候不知道哪一步坏了**：框错了？字没学？阈值太高？还是这张卡根本没进模板？

于是把中间过程全摊开，做成一个可以「看一眼就知道该教什么」的页面。

### 怎么用

```bash
pip install -r requirements.txt
python -m screenlens serve --window "窗口标题的一部分"
```

打开 `http://127.0.0.1:8765`，点「抓一帧」；先「画区域」，再在右栏「教数字/教卡面」，最后看建议清单。

只回放截图也行：

```bash
python -m screenlens serve --samples 截图目录 --layout layouts/你的布局.json
```

### 我需要什么

我一个人只有一种 UI 的样本，所以想请愿意折腾的人帮三件事：

1. **素材**：任意游戏/软件截图 + 你想识别的区域（分辨率、字体、是否高分屏）；
2. **布局**：调好的 `layout.json` 发我，我攒一个布局库；
3. **踩坑**：哪种情况认不出来、你怎么绕过去的。

不要求 star，能用、能提问题就行。

### 已知限制

- 数字要求同字体同字号，换字体要重学；
- 不做透视矫正/旋转/多语言；
- 单位/星级要教过才认；
- 仅 Windows（抓窗口用 PrintWindow/BitBlt）。
