# 公开归档说明

本仓库不仅保留可运行代码，也保留对后续维护者有用的复盘、参考数据与开发历史。归档原则是：**保留可复用资产，不公开私人对局、本机配置或私服专用数据。**

## 已保留

- `docs/PROJECT_RETROSPECTIVE.md`：停止个人开发时的项目状态、技术判断、可复用模块与重启路线。它是历史记录，不代表正式服识别能力已经通过认证。
- `refs/stronghold/`：来自社区 GPL-3.0 同人复刻项目的公开规则与数值参考快照；仅供研究，不是运行时必须下载的数据包。
- `tools/screen-lens/`：独立 Screen Lens 的源码、文档、演示与测试。归档中的自动内容切格实现已合并到这里，并补充回归测试。
- `archive/screen-lens-history.bundle`：Screen Lens 独立仓库的脱敏 Git 历史，保留初始发布提交 `a1c5f0c`；仅新增本机交接便签的后续空提交未保留。自动切格等归档时未提交的工作区代码以当前源码树为准。

恢复 Screen Lens 历史仓库：

```bash
git clone archive/screen-lens-history.bundle screen-lens-history
```

## 没有公开

原始 `covenant-archive-2026-11-07.zip` 不直接发布，因为其中仍含：

- `_refs/private/` 私服专用配置与数据；
- `var/` 中的对局账本、匹配记录、本机布局、识别模板与设置；
- 过程截图、诊断输出、协作留言和本机路径；
- 缓存、构建产物、重复代码副本及归档工具可执行文件。

这些内容对复现作者本机环境有用，但不适合作为公开社区仓库的一部分。需要识别证据时，请贡献者提供可公开的合成样本或明确授权的脱敏截图，而不是上传私人对局存档。

## 许可口径

归档复盘中的历史许可表述仅作记录。当前仓库以根目录 `LICENSE` 为准：根项目 GPL-3.0，`tools/screen-lens/` 保留 MIT；第三方数据与素材遵循各自许可。
