## 二、今天已经做完的

1. **数据包支持核心盟约二选一**
   - `pack.json` 新增可选键 `core_bond_groups: [["yanShip", ...], ["sargonShip", ...]]`；
   - `Pack.available_operators(mode, extra_inactive=...)`：没选中的组按「禁用盟约」处理；
   - `GameState.choices = {"bond_group": 0|1}`，进存档、进快照；
   - 池子（`calc/pool.py`）与概率（`calc/odds.py`）都走这个过滤；没配组时行为与旧版完全一致。
2. **面板**：`开新局` 弹窗多一个「核心盟约组」下拉（数据包没有这个键时自动隐藏）；选择随 reset 写进 `state.choices`。
3. **换包对比工具** `scripts/diff_packs.py`：明天重建数据包后，先跑
   `py -3 scripts/diff_packs.py packs/act2autochess packs/act2autochess-20261108`
   直接看新增/删除/改动（干员、盟约阈值、商店表、经济）。
4. 测试 91 全绿（新增 3 条：组过滤、空盟约干员不受影响、choices 往返）。

## 三、明天（11/8）的顺序

1. 启动器更新 → 进一次「独立模拟」，确认核心盟约二选一界面真实存在；
2. 抓 activity_table / 用社区包重建 `packs/act2autochess-20261108`；
3. `diff_packs.py` 看改了什么，重点：新增盟约、被禁干员、商店表；
4. 把新的 `core_bond_groups` 填进 `pack.json`（两组的 bond id 从界面或数据里抄）；
5. `/teach` 重标：整备区（装备分区后可能变两块）、商店格数、HUD；
6. `py -3 -m covenant doctor` 必须 0 缺项；
7. 打一局：开局选组 → 看池子人数/概率是否符合预期 → 记录一局。

## 四、还没想清楚、明天要验的

- **自选编队**：6+6 个自选干员是「开局就在手里」还是「只在商店里必出」？
  - 若开局在手里：它们应该从共享池里扣掉（和我们买牌一样）；
  - 若只是必出：池子不变，但首次刷新概率不同。
- **助战 30 名**：助战干员是否进共享池？（多人模式下别人也能刷到？）
- **模拟等级**：高等级是否改商店等级/回合数？（前瞻只说敌人更强、奖励更多）
- **装备分区**：装备是独立整备区（10 格？）还是共用？影响「整备区满」的判定。

这几条都写在 `docs/LAUNCH_CHECKLIST.md` 的「11/8 待确认」里，明天逐条勾。
