# 卫戍协议记牌器：独立桌面窗口设计

日期：2026-11-07
状态：设计方向已获用户确认，等待书面规格复核

## 1. 目标

把现有战术操作台装进真正独立的 Windows 桌面窗口，去掉浏览器地址栏、标签页和菜单，并提供完整操作台与紧凑置顶小窗两种形态。窗口能力不得侵入识别、记牌、概率、经济、存档或统计逻辑。

## 2. 技术方案

采用 `pywebview` 调用系统 Edge WebView2 渲染现有本地页面。Python 进程继续启动现有 `AppServer`，桌面壳只负责窗口生命周期、视图控制与状态保存。

不采用 Electron、Tauri 或 Edge `--app` 模式；不重写前端，不打包 exe，不引入前端框架。

## 3. 范围

### 包含

- 新增独立的桌面窗口模块和命令行 `--desktop` 启动开关。
- 完整／紧凑模式切换、置顶开关及浏览器环境降级。
- 窗口位置、尺寸、模式和置顶状态保存。
- 桌面快捷方式改为桌面窗口启动，保留原浏览器启动路径。
- Python 单元测试、前端行为测试和真实 Windows 窗口验证。

### 不包含

- PyInstaller 打包、安装器、自动更新或多窗口管理。
- 无边框自绘标题栏、透明覆盖层和跟随游戏窗口定位。
- 修改游戏规则、识别算法、API 数据结构和已有对局存档。
- 读取内存、注入游戏或修改游戏客户端。

## 4. 模块与接口

新增 `covenant/ui/desktop.py`，负责：

- 加载、校验和原子保存 `var/desktop.json`。
- 创建桌面窗口并注册生命周期事件。
- 向前端暴露最小 JS API：`get_state()`、`set_compact(value)`、`set_on_top(value)`。
- 将窗口事件转换为持久化状态，关闭窗口时通知主流程退出。

`covenant/__main__.py` 只在 `--desktop` 模式下调用桌面模块。现有 `serve`、`demo`、教学和社区命令的默认行为保持不变。

前端新增少量桥接代码：检测 `pywebviewready`，连接两个窗口按钮，并根据当前模式切换 `body` 的 `compact` 类。没有 `pywebview` 时隐藏桌面专属按钮，不发送无效桥接调用。

## 5. 窗口行为

### 完整模式

- 首次默认尺寸为 1280 × 840；窗口全局最小尺寸为 400 × 500，以兼容同一窗口切换到紧凑模式。
- 使用系统原生标题栏，可缩放、最小化、最大化和关闭；完整模式缩窄时沿用现有响应式布局。
- 显示当前完整对局／统计界面，所有现有功能保持可用。
- 首次启动不默认置顶，用户可手动开启。

### 紧凑模式

- 切换后尺寸为 430 × 760，位置沿用当前窗口左上角，并约束到可用屏幕范围。
- 默认开启置顶；用户仍可关闭置顶。
- 页面集中显示对局状态、主操作、商店、整备区和战场。
- 右侧情报栏收起，非关键品牌副标题与数据包信息隐藏。
- 切换统计或打开设置、选人、教学等复杂流程前恢复完整模式；关闭这些流程后不自动切回紧凑，避免窗口反复跳动。
- 紧凑模式不是透明覆盖层，不遮挡或拦截游戏窗口输入之外的区域。

### 关闭与浏览器兼容

- 关闭桌面窗口时保存状态并结束本次桌面服务进程。
- 普通浏览器启动不加载桌面壳，也不因浏览器标签页关闭而退出服务。
- 缺少 `pywebview` 或 WebView2 初始化失败时，输出明确原因并回退系统浏览器；不修改对局数据。

## 6. 状态保存

配置路径为当前服务 `--var` 目录下的 `desktop.json`，与 `engine.json` 分离。

保存字段：`compact`、`on_top`、`width`、`height`、`x`、`y`。仅接受布尔值与有限范围内的整数；非法 JSON、未知字段或越界值回退到安全默认值。

在模式切换、置顶切换、移动／缩放结束和窗口关闭时保存。高频事件使用短延时合并写入，避免连续磁盘写入。保存采用同目录临时文件替换，写入失败只提示窗口状态未保存，不得阻断窗口关闭或影响对局存档。

## 7. 错误与并发处理

- 桌面模块 import 失败时，仅桌面模式输出安装提示并回退浏览器；普通模式不 import 该依赖。
- 桥接调用必须等待 `pywebviewready`，调用失败时显示可读提示并恢复按钮可用状态。
- 前端始终保留真实快照轮询；窗口切换不清空搜索、弹窗输入或当前对局。
- 多实例仍使用各自 `--var` 目录；同一配置文件的并发启动不在本次扩展窗口锁范围。

## 8. 桌面快捷方式

现有“卫戍协议记牌器”快捷方式继续使用用户的 Python 3.12 和端口 8766，增加 `--desktop --window Arknights`，不再由 `pythonw` 打开系统浏览器。

依赖安装只作用于该项目实际使用的 Python 环境，并在文档中记录命令。保留命令行 `python -m covenant serve --window Arknights` 作为浏览器启动方式。

## 9. 验证与验收

1. 配置校验、原子保存、模式切换、置顶切换和关闭通知有 Python 单元测试。
2. 桌面桥接不存在时，现有前端测试和浏览器页面行为不变；存在时，按钮状态和模式切换有前端测试。
3. 完整 Python 测试、Node 测试、脚本语法、自检和 HTTP 冒烟全部通过。
4. 实际 Windows 窗口中确认无浏览器地址栏，完整／紧凑切换、置顶、移动、缩放、关闭均有效。
5. 重启后恢复上次模式和窗口状态；损坏配置不会阻止启动。
6. 对局／统计切换、搜索、设置、选人及真实快照更新在桌面窗口中保持可用。
7. 同步原项目前重新比较目标文件并备份，保留 DeepSeek 的并发修改。

## 10. 完成标准

用户双击桌面图标后进入独立应用窗口，而不是浏览器；可以在完整操作台和紧凑置顶小窗之间切换，重启后保留窗口偏好，所有原有记牌功能和数据口径不变。
