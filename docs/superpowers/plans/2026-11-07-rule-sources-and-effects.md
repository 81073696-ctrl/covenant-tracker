# 规则来源、刷新归因与经济效果实施计划

日期：2026-11-07  
依据：`rule-audit-20261107/卫戍协议规则与数据包对照.md`  
执行方式：当前会话内直接实施，不使用子代理，不做 Git 提交、合并或推送。

## 目标与边界

1. 数据包明确展示规则版本、来源性质与置信度；非官方复刻内容不得标成官方客户端数据。
2. 刷新记录区分为普通、免费、特殊与未归因商店变化；保留旧事件兼容，自动识别不模拟随机数。
3. 以数据包 `effects` 驱动坎诺特、远见、奇迹的经济效果；一次性奖励和永久折扣必须防重复、可重放。
4. 保留按模式区分的 9／14／19 回合与风丸两张合成规则。
5. 装备、机变、免费招募、隐秘核心和多人联防仍属未覆盖范围，只在 UI 与文档中明确提示。

- `covenant/services/capture.py`：仅在同对局、同回合、同等级、阵容不变、完整商店变化且证据稳定时记录；普通／特殊付费与零扣款未知分别归因，重复帧去重。

- `covenant/state/events.py`：重放跳过新增纯审计事件。

## 任务 5：先用失败测试锁定经济效果与永久标记

- `tests/test_core.py` 覆盖：
  - 坎诺特自动继承，剩余至少 5 时下回合额外 1；手动覆盖不污染新局。
  - 远见每 10 层 +2；首次 80 层仅远见干员购买价 -1；首次 150 层扩大到全商店。
  - 奇迹每 100 层 +20；免费概率仅展示 `(18+0.3×层数)%`。
  - 层数先高后低、重复设置、事件重放均不重复发钱或撤销永久解锁。
  - 未激活盟约不发经济奖励；默认 9 回合与风丸 `merge_num=2` 保持不变。
- 运行定向测试，确认现有 reducer 缺少这些效果。
