# v2.0 插件化方案（给更多人用）

> v1.0 是「自己能用」：本机 Python + 浏览器面板 + 私服校准。
> v2.0 的目标是「别人也能装」，但**仍然只读屏幕、不改游戏**。

## 1. 先说清楚「插件」在明日方舟 PC 端意味着什么

明日方舟是 Unity + IL2CPP 的独立客户端，没有 Overwolf / 暴雪那种官方插件接口，
也没有对外的 Match API。所以「插件」只有三种可行形态：

| 形态 | 做法 | 代价 |
| --- | --- | --- |
| **外部伴生进程**（推荐） | 独立 exe，抓窗口画面 + 本机网页面板 | 需要用户手动摆窗口；无注入、无风险 |
| 遮罩层 | 半透明置顶小窗，贴在游戏窗口上方 | 多显示器/缩放要适配；全屏独占会挡不住 |
| 游戏内注入 | 改 DLL / 读内存 | **不做**：违反用户协议，且随时可能封号 |

v2.0 只做前两种，且明确写进 README：**不读内存、不注入、不改客户端**。

## 2. 交付形态

```
CovenantTracker.exe          # 打包后的单文件（PyInstaller）
  ├─ 首次启动：解压到 %LOCALAPPDATA%\CovenantTracker\（数据包/模板/日志）
  ├─ 托盘图标：打开面板 / 开始识别 / 退出
  └─ 浏览器面板：127.0.0.1 随机端口（默认不对外）
```

- 打包用 PyInstaller（`--onefile --windowed`），依赖只有 numpy + Pillow，体积可控（约 40–60MB）。
- 首次启动引导：选窗口 → 体检 → 进 /teach 校准 → 打完第一局。
- 更新：程序内置「检查数据包更新」，只换 `packs/` 目录，不动 exe。

## 3. 数据边界（必须写死）

| 数据 | 默认 | 说明 |
| --- | --- | --- |
| 对局记录 | 只在本机 `var/matches.jsonl` | 不自动上传 |
| 截图 | 不落盘 | 只在内存里识别；除非用户手动「保存这一帧」 |
| 上传社区 | 显式点击 + 可预览 | 只传对局摘要，不含截图/账号 |
| 设备标识 | 无 | 没有账号、没有机器码、没有 IP 入库 |

社区汇总沿用 v0.3 的 `covenant community`：JSONL 落盘、按 id 去重、
每 IP 限流、可加 token；v2.0 只需要把「上传」做成面板里的一个按钮 + 预览。

## 4. 面板要补的东西

1. **设置页**：窗口选择、识别间隔、阈值、数据包切换、日志目录。
2. **首次引导**：四步（接窗口 → 框区域 → 学数字 → 试识别），每步都能跳过。
3. **错误可读**：抓不到窗口 / 全黑帧 / 模板缺失，都给一句人话 + 一个「怎么办」。
4. **崩溃日志**：`var/logs/app.log`，面板上一键导出（脱敏，不含截图）。

## 5. 多人（合作模式）怎么处理

卫戍协议是 1–4 人合作，但**队友的商店你看不到**。v2.0 不做「偷看队友」，
只做两件事：

- 共享卡池：队友买了什么，靠人工在面板上「记录队友购买」补记（一条命令/一个按钮）；
- 社区汇总：各人上传自己的终局记录，服务端合并后给「出场率/通关率」，与个人样本同一口径。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 官方 UI 大改 | 所有坐标都在数据包/布局里，改 JSON 不改代码；体检会指出缺哪块 |
| 被误认为外挂 | README 首屏写「只读屏幕、不注入、不改客户端」；开源可审计 |
| 数据版权 | 干员名/图标来自游戏素材，仓库只放**识别模板**不放原图；文档注明非官方 |
| 社区数据脏 | 服务端校验（已有 `_valid_record`）、按 id 去重、样本量阈值 |
| 打包被杀软误报 | PyInstaller onefile 常见；提供 zip 版 + 校验和 |

## 8. 现在就能做的三件事

1. `scripts/install_private_templates.py` 之外，再加一个 `scripts/export_templates.py`，
   把 `var/` 里的布局与模板打成 zip，方便换机器 / 分享给朋友。
2. 面板加一个「上传本局到社区」按钮（先预览 JSON，再 POST）。
3. 把 `run.bat` 换成一个 `start.vbs`（无黑框启动）+ 托盘图标。

这三件都不依赖官方更新，随时可做。
