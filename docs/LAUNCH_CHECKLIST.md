# 官方上线当天的校准清单（v1.0 → v1.1）

明天（11/8）官方更新后，数据包和 UI 都可能变。照这个顺序做，**每一步都能单独验证**，
不要一上来就开一整局。

先跑一次体检，知道现在缺什么：

```powershell
py -3 -m covenant doctor
```

体检只读数据包/布局/模板，不连游戏。缺项会直接告诉你补哪里。

## 0. 更新前（今天就能做）

- [x] 私服链路跑通：HUD 120/120、商店 95%（0 错认）、169 个测试全绿
- [x] `docs/PRIVATE_SERVER.md` 记录了启动、导帧、训练、回放
- [ ] 把 `var/` 备份一份（`xcopy /E /I var var-backup-1107`）

## 1. 数据包（5 分钟）

1. 看客户端有没有新表。有就按 `docs/DATA_PACK.md` 重新生成：
   ```powershell
   py -3 -m covenant pack --refs <新数据目录> --season 2026-11-08
   ```
2. 没新表就先沿用 `packs/act2autochess-private`；**在 pack.json 里把 `season` 改成 `2026-11-08`**，
   并把 `source` 写清楚「沿用 2026-03 私服数据，待官方校准」。
3. 跑 `py -3 -m covenant selftest`：能打印模式/池子/升级价就说明包没坏。

## 2. 界面（10 分钟）

1. 启动 `run.bat`（或 `py -3 -m covenant serve --window Arknights`）。
2. 进 `/teach`：
   - 框 资金 / 等级 / 回合 / 生命（**框紧**，别带边框）；
   - 框 商店（L1 与 L2+ 各一个区域，`params.levels` 分别填 `[1]` 和 `[2,3,4,5,6]`）；
   - 框 整备区 / 战场（可选，先不学图标）。
3. 学数字：至少 0–9 各一次，多学几种字号（大数字、小数字各来一遍）。
4. 学干员：先学当前池里常见的 20–30 个；点商店格 → 选干员 → 学习。
5. 学结算：通关画面、失败画面各学一次（第 5 节）。
6. 再跑一次体检：
   ```powershell
   py -3 -m covenant doctor
   ```
   目标是「没有缺项」。

## 3. 试识别（5 分钟）

1. 开一局，停在商店，点面板上的「识别这一帧」（或 `POST /api/vision/read`）。
2. 核对四件事：资金、等级、回合、生命是否和游戏一致；商店三/四张卡是否认对。
3. 认错的卡：回 `/teach` 补学那张；认不出但没错的，先放着（unknown 比认错好）。
   - **认不出来先开 `/lens`（识别工作台）**：它逐区域列出「读到什么 / 每个字最像什么 / 为什么跳过」，
     顶部会直接写「数字模板缺 0/5/6/7/9」这类硬缺口；补 5 个数字通常就能救回大半读数。
4. 打开「本局刷新」，刷新一次 → 点「确认商店」，确认账本记录了这一刷。

## 4. 开一局完整的（15 分钟）

- 正常打完一局（或打到第 3 回合就退，记 `quit`）。
- 结束时看顶部有没有「识别到结算画面」；有就点「记录本局」，杯数手填。
- 去统计页确认：对局 +1、终局阵容/盟约/按回合都有数。

## 5. 如果 UI 变了

| 现象 | 处理 |
| --- | --- |
| 数字认不出 / 认错 | 重新学字形；检查区域是否框到了新位置 |
| 商店卡全 unknown | 重新框商店区；确认 `params.art`（卡面上部比例）仍是 0.66 左右 |
| 等级读不到 | 等级区可能改成了图标而非数字，先手填，再考虑加模板 |
| 结算识别不到 | 重新学通关/失败；结算画面可能有动画，等稳定帧再学 |
| 卡池/价格对不上 | 优先改数据包，不要改代码 |

## 6. 回滚

- 布局/模板坏了：`copy var-backup-1107\layout.json var\`，模板同理。
- 数据包坏了：`packs/` 里上一版目录还在，`load_latest` 按 mtime 取最新，把旧目录 touch 一下即可。

## 判定「今天能不能用」

- 体检无缺项；
- 试识别四件 HUD 全对；
- 商店至少认对 2/3；
- 能记录一局并出现在统计页。

四条都满足就可以边玩边记；有一条不满足，就先只用手填模式（面板上可以直接点选商店），
统计照常能记。

### 体检结果怎么读

- ✗ = 阻塞项：布局没框、HUD 缺区、商店格数没覆盖、干员模板一个都没有——先补这些；
- ! = 提醒项：数字没学全、结算画面没学——不挡用，但资金/生命位数变了会读不出来，结算横幅也不会弹；
- 商店区 params.chars 指定只读前几格（L1 是 3 个干员 + 1 个道具），道具格不参与统计。
